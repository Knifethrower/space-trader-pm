#S About and License
Space Trader for handheld consoles is a port of the open-source Android version of Space Trader. It is free software, and you are welcome to share it under the terms of the GNU General Public License, which is in the License section of this help.
#T Credits
Space Trader was created by Pieter Spronck for the Palm OS.
The Android version is by Russell Wolf (Copyright © 2014-2016 Russell Wolf, all rights reserved except as granted by the license in the License section) and is based on code by Pieter Spronck.
This handheld port uses the game rules, text, help manual and artwork of that Android version. It adds a new front end, written in Java with libGDX, so the game can be played with a gamepad on PortMaster devices. The original authors have not reviewed or endorsed this port.
