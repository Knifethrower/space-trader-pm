Original source archive

com.brucelet.spacetrader_23_src.tar.gz is the complete source of the Android version of
Space Trader (package com.brucelet.spacetrader, version 2.3) by Russell Wolf, based on
the Palm OS game by Pieter Spronck. It is kept here because the original online
repository is no longer available.

Both are licensed under the GNU General Public License, version 3 or later. The license
notice is in readme.txt inside the archive.

This port's game rules come from this code: reference/GameState.java.orig is the
GameState.java class from it, and the tools/ scripts turn that into core/.../GameState.java.
The archive is unchanged apart from being gzip-compressed (the file we received was an
uncompressed tar with a .tar.gz name).

To unpack it:
  tar -xzf com.brucelet.spacetrader_23_src.tar.gz
